# ระบบวางแผนกะสตูดิโอสถานีโทรทัศน์ (Studio Shift Planner)

เว็บแอปพลิเคชันสำหรับจัดตารางกะการทำงานประจำสัปดาห์ของสตูดิโอโทรทัศน์ (เริ่มสัปดาห์วันอาทิตย์, ทีม A–E + ตำแหน่งพิเศษ CAM3, กะปกติ 5 วัน และกะพิเศษหมุนเวียนวันที่ 6)

## การรันใช้งาน (Development / Antigravity IDE)

```bash
npm run dev
```

จากนั้นเปิด `http://localhost:3000`:
- **พนักงานทั่วไป**: เปิดดูหน้าตารางงานได้ทันทีโดยไม่ต้อง Login
- **Admin**: กดปุ่ม **"เข้าสู่ระบบ Admin"** มุมขวาบน (ค่าเริ่มต้นใน `.env`: ชื่อผู้ใช้ `admin` / รหัสผ่าน `studio-admin-2026`)

## การเชื่อมต่อฐานข้อมูล PostgreSQL ภายในสถานี

1. แก้ไขค่า `DATABASE_URL` ในไฟล์ `.env` ให้ชี้ไปยังเซิร์ฟเวอร์ PostgreSQL ภายใน และเพิ่ม `PG_CONNECTED="true"`
2. รันคำสั่งสร้างตารางและข้อมูลตั้งต้น:
   ```bash
   npm run db:generate
   npm run db:push
   npm run db:seed
   ```
   *(หมายเหตุ: หากยังไม่ได้เชื่อมต่อเซิร์ฟเวอร์ PostgreSQL ระบบจะบันทึกข้อมูลลง `data/local-store.json` อัตโนมัติเพื่อให้ใช้งานและทดสอบได้ทันที)*
3. หากต้องการล้างข้อมูลทั้งหมดเพื่อเริ่มต้นระบบใหม่ตั้งแต่ต้น (ลบทั้ง `data/local-store.json` และรีเซ็ตตารางใน PostgreSQL):
   ```bash
   npm run db:reset
   ```
